# CLAUDE Examples

NRSP examples generated by Claude (Anthropic) demonstrating v0.4.0 specifications across multiple genres and use cases.

## Campaign Examples

### [01_Guildmaster_Investigation/](./01_Guildmaster_Investigation/)
**Complete Campaign Session** (7 files - All 6 NRSP file types)

Fantasy political intrigue demonstrating the full modular NRSP system. A murder investigation gone wrong, with the investigators framed for the crime they were trying to solve.

**Demonstrates:**
- All 6 file types (NRSP, SLD, CS, LS, NPC, LGM)
- Public/GM information split
- Cross-file linking
- Complete session workflow

---

### [02_Datacore_Heist/](./02_Datacore_Heist/)
**Heist Scenario** (2 files - NRSP + SLD)

Sci-fi casino heist on Nexus Station. Demonstrates NRSP working in non-fantasy settings with branching narrative paths and detailed session logs.

**Demonstrates:**
- Sci-fi genre adaptation
- Session log structure
- Branching paths (AlternateNext)
- Minimal viable example (no separate character/location files)

---

### [03_Weeping_Spire/](./03_Weeping_Spire/)
**Standalone Scenario** (1 file - NRSP only)

Dark fantasy horror encounter with a crystalline entity. Shows how NRSP works as a self-contained format with embedded character information.

**Demonstrates:**
- Standalone NRSP file
- Dark fantasy/horror genre
- Multiple branching paths
- Embedded character snapshots (no separate CS files)
- Timeline references to non-existent files (showing campaign continuity)

## Use Cases Demonstrated

1. **Full Modular System** - Guildmaster Investigation shows all 6 file types working together
2. **Minimal Viable** - Datacore Heist shows NRSP+SLD without character/location sheets
3. **Standalone Format** - Weeping Spire shows single-file NRSP with embedded information
4. **Cross-Genre** - Fantasy, sci-fi, and horror examples
5. **Branching Narratives** - AlternateNext paths in all three examples
6. **Public/GM Split** - Character secrets (NPC) and location secrets (LGM) in Guildmaster
7. **Timeline Continuity** - Previous/Next SavePoint references across campaigns
